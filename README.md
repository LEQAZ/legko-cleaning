# ЛЕГКО — сайт клининговых услуг

Учебный проект для портфолио: две страницы для уборки квартир и частных домов с интерактивным расчётом стоимости.

**[Открыть сайт](https://leqaz.github.io/legko-cleaning/)** · [Страница частного дома](https://leqaz.github.io/legko-cleaning/house.html)

![Страница уборки квартир](screenshots/desktop.png)

## Задача и результат

Помочь посетителю выбрать уборку и понять, из чего складывается цена. Для квартиры и дома предусмотрены отдельные визуальные темы и дополнительные зоны: балкон, крыльцо, терраса, лестница.

- Адаптивный интерфейс для компьютеров и телефонов.
- Калькулятор с отдельными строками площади, доплаты до минимальной стоимости и дополнительных услуг.
- Сохранение выбранных услуг и положения страницы при переключении объектов.
- Переключение страниц ссылками и перетягиванием свободного фона мышью.
- Анимации с учётом системной настройки уменьшения движения.
- Проверка формы и демонстрационное подтверждение заявки.

## Технологии и участие

HTML, CSS, JavaScript (ES modules), SVG. Без сторонних библиотек в интерфейсе и без серверной части.

Автор проекта — LEQAZ: концепция, направление дизайна, требования к услугам и проверка сценариев. Реализация и тестирование выполнены совместно с ИИ-помощником.

## Проверка

14 автоматических тестов расчётов и сохранения настроек. Локальная проверка в Edge: обе страницы, ширина 320/390/1440 px, формы, расчёты, перетягивание, сохранение выбора и прокрутки.

```sh
npm test
```

Для запуска из корня проекта:

```sh
python -m http.server 5500 --bind 127.0.0.1 --directory dist
```

Откройте http://127.0.0.1:5500. Подробности устройства и локальной проверки: [DEVELOPMENT.md](DEVELOPMENT.md).

## Демонстрационные условия

Это учебная работа, а не выполненный коммерческий заказ. Название компании, тарифы и условия демонстрационные. Форма не отправляет заявки; контактные данные не сохраняются. Настройки калькулятора сохраняются в sessionStorage текущей вкладки.

Интерьеры созданы с помощью ИИ и не представляют реальные выполненные заказы. Источники изображений описаны в [ASSETS.md](ASSETS.md), оформление бренда — в [BRAND.md](BRAND.md).

Исходники находятся в `main`, публикуемая статическая версия — в `gh-pages`.
